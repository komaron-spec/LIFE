# LIFE SYSTEM

Personal **Real World Interface** — a mobile-first offline PWA that turns current time, location, weather, and local records into a gentle game HUD.

## Use it

1. Open the deployed site on your phone.
2. Tap **SYNC** and allow location access to resolve your current area and weather.
3. On iPhone Safari, tap Share → **Add to Home Screen**. On Android Chrome, use **Install app**.

Your world state, daily entry status, and log are stored only in that browser. The app still opens offline with the last successful sync.

## Deploy with GitHub Pages

This repository includes a deployment workflow. In GitHub, open **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**, then push to `main`. The site will be published at:

`https://komaron-spec.github.io/LIFE/`
